# Diana × ZCode 视觉样板

这是一份按 ZCode 3.6.5 桌面端实际结构复刻的视觉与交互样板，用于确认美术位置、日夜配色、文字可读性和消息导轨反馈。

- 入口：`/theme-preview/index.html`
- 日间：`?theme=light`
- 暗夜：`?theme=dark`
- 干净截图：再加 `&clean=1`
- 导轨密度样板：再加 `&railCount=12`（支持 1–240）
- 快捷键：`D` 切暗夜，`L` 切日间

启动本地预览：

```powershell
npm run dev
```

自动生成并校验暗夜/日间在 1200×800 与 2560×1392 下的四张截图：

```powershell
npm run qa:theme-preview
```

校验同时覆盖 12、50、100、220 条消息：保留 36×10px 原生命中区，只改变 2px 可见线段；按稀疏、均衡、密集三档生成不规则起伏，每 5 条设置一条主刻度，并确保首尾菱形与唯一当前星标存在。悬停时继续使用 ZCode 原生的三阶邻域波形（当前项 2.6×、相邻项 1.7×、次相邻项 1.25×），移出后恢复 Diana 静态起伏；点击项同步唯一高亮。

## 边界

这份浏览器样板本身不是“已经挂载到 ZCode”的证明。它不会修改 `app.asar`、安装目录或启动参数，也不会开启 CDP、调试端口、监听服务或开机自启。

2026-08-28 曾通过一套另行批准、仅留在用户目录的临时适配器验证 ZCode 3.6.5.4145；该运行时不进入本目录、Git 或发行包，也不代表普通启动会自动挂载。`theme-blueprint/` 只保存日夜色值和装饰层契约；后续若要适配新版本，仍需重新进行受控、可回退的界面勘测并单独征得用户同意。
