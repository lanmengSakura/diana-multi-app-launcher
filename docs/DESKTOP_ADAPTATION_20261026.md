# 2026-10-26 桌面版本适配（RC.8）

本次不重新设计美术。先前源码候选已整理进 RC.8；提供新下载文件，不覆盖旧 RC.7 文件。

> 以下记录描述 RC.8 的历史范围。RC.10 已补齐新版 ZCode 的独立公开适配组件，新用户无需个人登记；当前使用说明以 [RC.10 发布说明](RELEASE_RC10.md) 为准。

## DeepSeek Harness 官方桌面端

- 目标：有效官方签名的 Windows Desktop `0.2.1-rc.3`（产品版本 `0.2.1.0`）。未知版本停止部署，不修改安装文件。
- “DeepSeek 桌面端”关联 `DeepSeek Harness.exe`；“DeepSeek 网页端”单独关联旧源码项目目录。既有目录保持网页入口，旧混合字段的 EXE 只读识别到桌面入口；不覆盖已保存的新桌面关联。
- 本机插件 `dsh-diana-theme` 使用官方插件管理器与 `theme.overrideTokens`，日夜跟随原生外观设置。装饰复用既有蓝图尺寸、断点和素材，挂在已核验的会话容器下，不重排原生输入区。
- 插件安装前正常退出应用；安装器只备份将修改的插件配置。不同插件内容使用不同本地包路径，并校验安装副本，避免官方管理器复用旧 file: 缓存。
- 原生插件页可禁用；启动器“原版启动”需先退出再撤下插件、普通启动。第三方插件会在应用中执行代码，应审阅来源；此插件没有调试连接、网络或账号/对话读取逻辑。
- 源码在 `plugins/diana-deepseek-desktop/`。`npm run build` 生成内嵌本地图片的插件；生成物不重复提交到 Git。对应主题仓库：[diana-dsh-theme](https://github.com/lanmengSakura/diana-dsh-theme)。

## ZCode 3.16.3.8992

- 新增的是本机登记加载与状态兼容，不是公开可用的一键新版适配器。旧内置适配仍限定原精确版本。
- 已核验的登记需要精确版本、证书标识和代码/素材 SHA-256；登记缺失、失配或文件变动时停止，不回退旧版来绕过检查。
- 未登录且主工作区未出现时显示“等待进入工作区”，不冒充挂载成功；进入可识别工作区后可手动再挂载。不复制登录态。
- 本机实验脚本、实际登记、状态、日志、会话和截图不提交。新调试会话仍须单独说明并取得同意；撤下皮肤不关闭端口，完整退出目标应用才关闭。
- 公开视觉蓝图与限制见 [diana-zcode-theme](https://github.com/lanmengSakura/diana-zcode-theme)。
