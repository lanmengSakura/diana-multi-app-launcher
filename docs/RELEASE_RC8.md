# Diana 多合一启动器 · Beta.4 RC.8

这是新的 **Windows x64 预发布版**，包含安装版和免安装便携版。请手动下载更新；旧 EXE 不会因源码提交而自动升级，RC.7 文件保留可供回退。

## DeepSeek 不再共用一个入口

| 入口 | 关联内容 | 操作与恢复 |
|---|---|---|
| **DeepSeek 桌面端** | 官方 Harness Desktop `0.2.1-rc.3` 的 `DeepSeek Harness.exe` | 原生主题插件；日夜跟随应用外观，插件页可禁用；启动器“原版启动”需完整退出后撤下插件并重开 |
| **DeepSeek 网页端** | 已完成主题合并与构建的 Harness 项目根目录 | 启动本地网页服务；“打开页面”不恢复源码，也不操作桌面端插件 |

网页端是原来的本地 Harness 源码项目，不是 DeepSeek 官网聊天页。两个入口独立记住路径和状态，浏览时一个选 EXE、一个选文件夹；目标缺失时不会自动改用另一种形态。

旧网页目录关联保持有效；此前本机试用版把 EXE 存在旧字段时，会只读识别到桌面端，下一次主动保存时才通过已有备份流程整理字段。已保存的独立桌面路径优先，失效路径仍提示修复。请在下拉列表选择需要的入口。

## 其他变化与限制

- 保留既有按钮尺寸、立绘、音乐动效及《Hopeful Dreamer》循环配乐。
- 加入 ZCode `3.16.3.8992` 的本机登记加载与等待工作区状态，但**新的实验适配器未放入公开包**；普通用户不会因此自动获得该版本完整挂载。原有内置 ZCode 仍限定 `3.6.5.4145`，不跳过版本、签名和文件摘要检查。
- 继承 RC.7 的 Codex 辅助窗口透明保护和旧 VS Code 安装目录美术层恢复提示。
- 官方 Harness 桌面插件复用原布局，不改安装文件或 `app.asar`，不打开调试端口，不读取账号、对话或调用模型。它仍是会在应用内执行的第三方插件，首次安装需知情确认。

## 下载与风险

- 安装版：`Diana-Multi-App-Launcher_0.1.0-beta.4-rc.8_x64-setup.exe`
- 便携版：`diana-multi-app-launcher_0.1.0-beta.4-rc.8_x64-portable.exe`
- 摘要：`SHA256SUMS.txt`

两种 EXE 均未签名，请只从本仓库 Release 下载并校验摘要。更新前正常退出旧启动器，保留回退文件；不需要卸载目标应用或清空账号。

已有 Codex、Cursor、Grok Bot、ZCode 实验挂载仍会在新开调试会话前说明风险并等待确认。回环端口不是认证，同机进程可能读取界面或执行渲染脚本；关闭启动器、撤下主题不等于关闭端口，须完整退出目标应用。详见 [风险说明](https://github.com/lanmengSakura/diana-multi-app-launcher/blob/main/SECURITY.md)。

## 验收边界

本次用不可执行夹具、模拟 IPC 和独立无头浏览器检查路径隔离、旧关联识别、保存/重置、按钮文字和演示路由；不连接正在使用的应用，也不复制登录态。完整构建、资源/音频摘要和最终下载包核验另见 [发布核验记录](https://github.com/lanmengSakura/diana-multi-app-launcher/blob/main/docs/RELEASE_RC8_VALIDATION.md)。

之前的本机 Harness Desktop 已检查插件安装、禁用、重新启用与暗夜装饰；实机日间、跨机器、原生文件选择框、干净机器安装/卸载等尚未全部验收。离线日夜截图不等于这些项目通过，打包成功也不等于所有目标版本兼容。旧 DeepSeek 网页演示不冒充新的桌面实机演示，本轮未更新线上站点。
