# Diana Multi-App Launcher · Beta.4 RC.11

Windows x64 预发布，内置 Codex 主题 1.3.5。可下载当前用户安装版或便携版，并用附件 SHA256SUMS.txt 核对。旧版启动器需要手动更新。

## Codex 跨版本更新

跨多个客户端版本更新后，Codex 首次启动可能需要先准备本地缓存。RC.11 把等待主窗口的上限从 50 秒延长到 180 秒。窗口和端口就绪便继续，启动进程提前退出则立即提示。

新聊天、普通对话和输入区现在可识别 Codex 26.1106.6628.0 的界面结构，同时保留旧版输入框和导轨的识别方式。日间与夜间都调整了新聊天插画、展开提问卡和附件时的人物遮挡、通知铃铛及右侧详情卡。更新后的客户端会先接受界面探测，遇到无法识别的工作区会停止挂载并提示。

## 导轨与音乐

消息刻度会响应客户端提供的音频强弱。弱拍也能带动较长的刻度，书签圆点跟随线尾，当前消息的星标保持清楚。皮肤通过 CSS 响应已有信号，没有新增音频采集进程、计时器或音频权限。Windows 版 Codex 26.1106.6628.0 尚未提供系统音频信号，播放电脑音乐时导轨保持静止。鼠标滑过和消息跳转照常可用。

## 本次核验

- 日夜布局和导航在隔离浏览器中通过。覆盖旧版及新版页面结构、12 至 217 条消息、展开输入区、切换页面、紧凑窗口和撤下主题。
- 217 条刻度的隔离对话中，日夜两套在静置三秒及写入一帧模拟音频电平时，主题额外请求的 JavaScript 动画帧与计时器均为 0。浏览器仍需绘制实际变化的刻度。
- 72 项 Rust 测试通过。另有 2 项需要真实应用的辅助测试未运行。应用关联 28 项、交付与轮询 9 项、网页路由 13 项均通过。
- 已核对便携版与安装器内的主程序。两者仅有 Tauri 打包类型标记的 3 个字节不同。包内 47 份独立受保护资源及原有配乐已核验。

本轮已核验当前 Windows 客户端安装包及隔离布局。干净机器安装和未来客户端版本尚待实机验收。实验挂载仍需在启动器内明确确认。 [挂载与恢复说明](https://github.com/lanmengSakura/diana-multi-app-launcher/blob/v0.1.0-beta.4-rc.11/SECURITY.md)
