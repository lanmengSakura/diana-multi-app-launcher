# Beta.3 发布校验 · 2026-09-06

本轮从公开 Beta.2 主线创建独立发布工作区，选择性同步已定稿的前端、美术和修正。未把开发仓库中的专用适配器、登录态、日志或歌曲原始文件提交到公开源码。

## 已通过

- Rust：29 项单元/回归测试通过；1 项真实应用动作 smoke 被明确忽略，未执行。
- 构建前完整性：12 个受保护 Codex 运行文件与 SHA-256/LF 清单匹配。
- `cargo fmt --check`、TypeScript 检查、Vite 生产构建、Tauri x64/NSIS 构建通过。
- 原生前端浏览器检查：8 个目标的按钮/恢复文案、连接臂展开/隐藏、可用状态通过。
- 音乐粒子：普通动效 3 个音符、减少动效模式 2 个音符，位移/淡出可测；暂停与播放错误后清除粒子，无控制台错误。
- 交互演示：首次静音、模拟挂载/等待退出/原版重启、8 个目标的公开能力边界、异常重试、关节折叠、音乐开关、窗口收起/重开、390px 窄屏无横向溢出，以及减少动效模式可用。
- 演示浏览器检查未发现第三方请求、本机应用端点请求或页面错误。
- 音乐完整原始字节已在发布 EXE 中找到，不是空音频占位。
