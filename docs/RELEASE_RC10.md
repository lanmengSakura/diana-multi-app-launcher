# Diana Multi-App Launcher · Beta.4 RC.10

Windows x64 预发布。此版补齐 **ZCode 3.16.3.8992 的公开运行组件**，提供安装包与便携版，旧 RC.9 及更早附件不覆盖。

## 修复了什么

RC.8/RC.9 只支持读取用户另行制作的本机适配登记，普通用户关联新版 ZCode.exe 后，仍被旧 3.6.5.4145 的版本检查拦下。RC.10 按精确版本选择内置适配：**新用户不需要个人登记 JSON、作者目录或额外制作适配器**。

- 支持范围是官方签名的 **3.6.5.4145 / 3.16.3.8992**，不是放开所有版本。3.16 还校验精确程序资源摘要。
- 补充 Windows 安装登记与运行进程位置发现；非默认目录仍可手动关联实际 `ZCode.exe`。不会执行注册表中的卸载命令，也不会自动覆盖原关联。
- 沿用原日间/暗夜美术与响应式布局，新版装饰挂在原生会话容器底层，不拦截输入；自动模式跟随 ZCode 原生外观。
- 尚未登录或进入主工作区时显示等待状态；进入工作区后再点击挂载，不读取或迁移登录态。
- 新运行组件使用独立版本目录，旧适配及恢复记录保留；已有本机登记继续优先，无效登记不静默绕过。

## 用户怎么更新

1. 下载下方 RC.10 安装版或便携版，核对 `SHA256SUMS.txt`。旧 EXE 不会自动更新。
2. 保存工作并完整退出 ZCode；打开新启动器，选择 ZCode。没自动找到时，在“关联”选择实际 `ZCode.exe`。
3. 选择日间/暗夜，点击挂载并阅读风险提示，自行决定是否继续。需要 Node.js 22+。
4. 如显示“等待进入工作区”，进入 ZCode 主界面后再点挂载。无需反复关联或复制他人的配置。

## 风险与恢复

此公开组件按用户明确选择启用，下载、打开或保存关联不是授权。新开会话前必须确认：调试端口仅绑定随机高位 `127.0.0.1`，但**没有身份认证**，同机同账户的其他进程可能读取可见内容、执行渲染脚本或截图。版本/签名/资源/进程身份校验不能消除这一风险。

短时适配器结束后目标应用仍持有端口。**撤下皮肤或关闭启动器不等于关闭端口；完整退出所有本次 ZCode 进程，再从官方入口普通启动才能结束暴露。** 不修改安装包、登录态或快捷方式，不创建服务、计划任务、自启动项或后台 watcher。详见 [安全说明](https://github.com/lanmengSakura/diana-multi-app-launcher/blob/main/SECURITY.md)。

## 验收范围

本机同版本已有未登录工作区的日夜/撤下/重挂载记录；本轮未关闭或启动真实 ZCode，未操作登录态。新版公开代码完成签名/程序资源只读预检、无个人登记的隔离解包与校验、日夜/自动/撤下布局测试和界面授权测试。具体记录见 [RC.10 核验](https://github.com/lanmengSakura/diana-multi-app-launcher/blob/main/docs/RELEASE_RC10_VALIDATION.md)。

这不是用户电脑上的实测结果，也不代表跨机器、登录后全部页面、完整退出普通重开等扩大验收已完成。仍保留预发布状态；请反馈具体应用版本与脱敏错误，不发送登录数据或聊天正文。网页演示未更新，定稿美术和内置配乐保留。
